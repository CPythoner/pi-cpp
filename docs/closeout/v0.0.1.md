# v0.0.1 Final Closeout

> 状态：**功能与文档 closeout 完成；重新打 tag 前只剩 tag ref 更新**  
> 日期：2026-09-03

## 1. 版本定位

`v0.0.1` 是 pi-cpp 的地基版本，目标是固定后续实现长期依赖的工程边界，而不是提供可调用真实 LLM 的 Coding Agent。

本版本最终交付：

- C++17 / CMake / Linux、macOS、Windows 三平台构建与测试骨架；
- `ai -> agent -> coding-agent` 三层 SDK 结构；
- public headers 位于 `include/pi/...`；
- CMake targets：`pi::ai`、`pi::agent`、`pi::coding-agent`；
- canonical namespaces：`pi::ai`、`pi::agent`、`pi::coding_agent`；
- `ai` Message / ContentBlock / Usage / StopReason；
- `agent` AgentMessage；
- L1 12 种 Provider events 与 L2 10 种 Agent events；
- CancellationToken / CombinedCancellation、ThreadGuard、string helpers；
- 三个手工 JSONL fixture round-trip；
- 三层独立 SDK consumer tests；
- `picpp --version`。

行为与 wire 规范来源固定为 **pi `v0.80.0`**；Tau `v0.4.1` 仅作实现参考。

## 5. 已知限制

这些不是 `v0.0.1` closeout 阻塞项：

1. 当前 JSONL fixtures 为手工构造，只证明 pi-cpp 自身序列化 round-trip，不构成真实 pi `v0.80.0` compatibility evidence；真实 fixture/reference harness/differential tests 从 `v0.0.2` 建立。
2. CancellationToken 当前仍存在 callback-under-lock 设计债；在 `v0.0.2` 进入真实 HTTP 前完成 callback 锁外执行与 unregister/request/destructor race 加固。
3. `coding-agent` 在本版本仅建立 target/public namespace/header 骨架；真实 read/write/edit/bash 从 `v0.0.4` 实现。
4. `cmake --install`、export targets 与 `find_package(picpp CONFIG REQUIRED)` 从 `v0.1.0` 完成。
